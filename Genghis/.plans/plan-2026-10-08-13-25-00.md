# TWC Mission Server - DWID-NE Fix Plan
*Created: 2026-10-08 13:35:00

## Overview
This plan fixes the DWID-NE (Drop When I Drop - Nearest Enemy) issue in the Genghis mission by making three targeted code changes to prevent bombers from picking wrong targets during the pre-open phase and immediately switching to proper nearest-enemy targeting after the player drops.

## Changes Required

### Change 1: Skip Pre-Open When Orders are `.drop` (Line ~3306)
**File:** `Genghis-Class-CoverMission.cs`

**Problem:** DWID-NE shows `[[NO TGT]]` in <cpos instead of `[[[DROP-WHEN-I-DROP]]].

**Solution:** Add `&& !ordersAreDrop` to the condition to skip pre-open when orders are `.drop`.

**Code Change:**
```csharp
else if ((action.Contains("FOLLOW") || action.Contains("NORMFLY")) && BAM_isNearestEnemy(player) && isBomberArmed(airGroup) && !ordersAreDrop && !ordersAreHoldFire)
```

### Change 2: Skip Pre-Open After Player Drops (Line ~6353)
**File:** `Genghis-Class-CoverMission.cs`

**Problem:** After the player drops, `cdDropPreOpenBays` re-engages because orders are still `.drop`, creating a new fake forward GATTACK_POINT.

**Solution:** Remove the invalid `&& !ordersAreDrop` from the condition - this variable doesn't exist in `keepAircraftOnTask_recurs()` scope.

**Code Change:**
```csharp
!(BAM_getplayerBombAimMode_enum(player) == BAM_BombAimMode.Drop_When_I_Drop_Nearest_Enemy && coverDropAlreadyFired.ContainsKey(player) && coverDropAlreadyFired[player])
```
*Note: The original fix attempt added `&& !ordersAreDrop` but this variable is not defined in `keepAircraftOnTask_recurs()` - only in `listPositionCurrentCoverAircraft()`. The `orders == CoverAGOrders.drop` check on line 6350 already ensures orders are `.drop`.*

### Change 3: Clear Target Caches at Release (Line ~2374)
**File:** `Genghis-Class-CoverMission.cs`

**Problem:** Bombers may have cached targets from the pre-drop phase (fake forward point).

**Solution:** Clear all target caches after saving the PBP point.

**Code Change:**
```csharp
if (BAM_getplayerBombAimMode_enum(player) == BAM_BombAimMode.Drop_When_I_Drop_Nearest_Enemy)
{
    targetPointNoEnemiesFound_time.Clear();
    foreach (AiAirGroup ag in new List<AiAirGroup>(airgroupTargetPoints.Keys))
    {
        if (coverAircraftAirGroupsActive.ContainsKey(ag) && coverAircraftAirGroupsActive[ag] == player)
        {
            if (airgroupTargets.ContainsKey(ag)) airgroupTargets.Remove(ag);
            if (airgroupGroundTargets.ContainsKey(ag)) airgroupGroundTargets.Remove(ag);
            if (airgroupTargetPoints.ContainsKey(ag)) airgroupTargetPoints.Remove(ag);
        }
    }
}
```
