### F2 — HIGH: `Dictionary<Player, Timer> COVER_ListPositionTimer` not thread-safe (CoverMission.cs line 2169)

- Declared plain `Dictionary<Player, System.Threading.Timer>`.
- Written/created on the mission thread (`COVER_DropWatchTimer[player] = new
  Timer(...)` pattern at ~2318; same pattern for the list-position timer),
  read/Disposed from the timer callback `listPositionCurrentCoverAircraft_obj`
  (line 3436) which runs on a thread-pool thread, and `Clear()`/`Dispose()`
  loops from `OnBattleStoped` (lines 420-427).
- `Dictionary<,>` is not thread-safe: concurrent Add/Remove/indexer on it can
  throw `InvalidOperationException` (modified during enumeration) or corrupt
  internal hash-bucket state → undefined behaviour / torn state.
- **Fix:** switch to `ConcurrentDictionary<Player, System.Threading.Timer>`
  (System.Collections.Concurrent already imported, line 13). C#5-compatible:
  `TryGetValue` + `Value.Dispose()`, `TryRemove`. Watch for any
  `foreach (Player p in ...Keys) ... [p]` enumeration that must become
  `foreach (var kv in COVER_ListPositionTimer)` to avoid read-then-read.

### F3 — HIGH: plain `Dictionary<AiAirGroup, ...>` cover state mutated from multiple threads (CoverMission.cs lines 172-184)

- `coverAircraftAirGroupsActive` (174), `coverAircraftAirGroupsOrders` (179),
  `coverAircraftAirGroupsTargetPoint` (178), plus the ~18 sibling per-group
  dicts cleaned up in `forgetAirGroup` (563-587) are plain `Dictionary<,>`.
- Concurrent accessors:
  - engine `Timeout()` callbacks (heartbeat ~16s, `checkPlayersCoverACDisappeared_recurs`
    re-arm every ~2.1 min inside a `Task.Run`, 10-min final-run stale timers),
  - `System.Threading.Timer` callbacks (20s `<cpos>` display, 0.75s drop watch),
  - `Task.Run` background sweeps (`renewAllStaticActors_recurs` line 287),
  - chat handlers (`Mission_EventChat`) on the mission thread.
- Enumeration + concurrent mutation (`foreach (AiAirGroup airGroup in
  coverAircraftAirGroupsActive.Keys)` in `listPositionCurrentCoverAircraft`
  ~3528 and in the heartbeat) while another thread `Remove`s is the classic
  corruption path (InvalidOperationException at best, torn hash-bucket state
  at worst).
- **Fix:** convert the hot, freely-cross-thread collections to
  `ConcurrentDictionary<,>`:
  - `coverAircraftAirGroupsActive`
  - `coverAircraftAirGroupsOrders`
  - `coverAircraftAirGroupsTargetPoint`
  - `coverAircraftAirGroupsReleased`
  - `coverAircraftAirGroupsIndexes` / `coverAircraftActorsIndexes` (nested
    inner dicts stay plain only if all mutation of an inner dict stays on one
    thread — prefer also converting inner dicts or copying before enumerate,
    as `removeFromAirgroupIndex` already does with `new Dictionary<>(agIndex)`).
  - the `forgetAirGroup` sibling dicts (566-583): `coverAGSpeedRatio`,
    `coverAGSpeedRequested`, `coverAircraftAirGroupsDropIssued`,
    `coverAircraftAirGroupsDroppedThisPass`, `coverAircraftAirGroupsBayWaitSince`,
    `coverDropPassLogged`, `coverRtbLogged`, `coverRtbNotified`,
    `coverPreOpenLast`, `coverSpawnBombCount`, `coverSpawnFuelKg`,
    `coverAircraftAirGroupsLoiterPoint`, `airgroupTargets`,
    `airgroupGroundTargets`, `airgroupTargetPoints` — `forgetAirGroup` runs
    on timer threads while chat handlers may read them.
  API mapping for C#5: `.Add(k,v)` → `TryAdd(k,v)` or indexer,
  `.Remove(k)` → `TryRemove(k, out ignored)` — **C#5: declare the `out`
  variable beforehand, no `out var`** — `.Keys.Contains(k)` →
  `ContainsKey(k)`, `foreach over .Keys` → `foreach (var kv in dict)`.
  NOTE: `ConcurrentDictionary` indexer get throws on missing key same as
  `Dictionary`; keep the existing ContainsKey guards.
- `numberCoverAircraftActorsCheckedOutWholeMission`, `playerIndex`,
  `coverAircraftActorsCheckedOut`, `PBP_playerBombPoint` — convert too if
  written from timer callbacks (check each during the pass).
- Deliberately do NOT blanket-convert everything blind: only convert
  collections with confirmed cross-thread access, to keep the diff reviewable.
