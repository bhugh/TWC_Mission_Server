# Plan: Remove `CoverAGOrders.drop` Orders Mode
*Created: 2026-10-11 23:33* (supersedes/next after plan-2026-10-11-2134.md)

CoverAGOrders.drop is a vestige of the original (different) implementation in -covermission.cs, and it is a confusing mash-up of orders mode and targeting mode. Eliminating it may also help with cover aircraft getting confused when changing from one targeting mode to another.

## Complete Plan to Remove `CoverAGOrders.drop`

__Goal:__ Delete the `drop` mode entirely and re-express "drop when I drop" through existing order/targeting semantics.

### How the drop behavior is now expressed

- "Sit on bombs until the leader drops" → the group is on an existing hold-fire order (`<cstrict` or `<creserve`), where `ordersBombGround` is already false and `ordersHoldFire` is true.
- "Tight formation / exact speed match" → use `<cstrict` (existing mechanism, `AltDiffPassed_m = -3`, `AltDiffPassed_range_m = 15`).
- The `<cdrop` label/targeting display → route through the bomb-aim-mode enum (`Drop_When_I_Drop` / `Drop_When_I_Drop_Nearest_Enemy`) only, which controls which target the player is playing for.
