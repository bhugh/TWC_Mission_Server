```javascript
  function readFrontLineFile() {
    var xmlhttp = new XMLHttpRequest();
    var serverId = "TWIN GRANDSONS OF KHAN";
    var filename = serverId + "_FRONT_radar.txt";
    var url = filename; // same directory as radar.php

    xmlhttp.onreadystatechange = function() {
      if (xmlhttp.readyState == 4 && xmlhttp.status == 200) {
        var lines = xmlhttp.responseText.split('\n');
        var latlngs = [];
        lines.forEach(function(item) {
          if (!item.trim()) return;
          var words = item.split(',');
          if (words.length >= 2) {
            var x = parseFloat(words[0]);
            var y = parseFloat(words[1]);
            if (!isNaN(x) && !isNaN(y)) {
              latlngs.push(new L.LatLng(y, x));
            }
          }
        });

        if (latlngs.length > 0) {
          if (frontLinePolyline !== null) {
            frontLineLayerGroup.removeLayer(frontLinePolyline);
          }
          frontLinePolyline = L.polyline(latlngs, {
            color: '#884',
            weight: 3,
            opacity: 0.7,
            smoothFactor: 1
          }).addTo(frontLineLayerGroup);
          if (!frontLineVisible) {
            frontLineLayerGroup.removeLayer(frontLinePolyline);
          }
        }
      }
    };
    xmlhttp.open("GET", url, true);
    xmlhttp.send();
  }
```

## Notes for the ACT MODE Worker

- **C#5 only**: Do NOT use `$"..."` string interpolation, `?.` null-conditional, `out var`, `is Type pattern`, or `nameof`. Use `String.Concat` / `+` for strings, `as` + null check, named `out` variables.
- The radar file format is `x,y` per line (comma-separated). The JavaScript `maplines()` function (already in radar.php) splits on `,`, so our format is compatible.
- Leaflet uses `L.CRS.Simple` where `LatLng(y, x)` maps to map coordinates. The existing map bounds are `[[8800,8550], [311040,360959]]` (x,y). Our radar file writes `x,y`, and the JavaScript reads it as `new L.LatLng(y, x)`.
- No changes to `Genghis-Class-StatsMission.cs` are needed — the existing `*_radar.txt` glob upload covers our new file automatically.
- The file is written every time `DrawFrontLinesPerMapState` is called with `test: false` (which includes the `OnBattleStarted` call at line 8778). This keeps the front line updated as the campaign map state changes.
- If `SERVER_ID_SHORT` changes per server (e.g., "TacticalTEST" on test server), the radar file name will automatically differ per server, preventing conflicts.
