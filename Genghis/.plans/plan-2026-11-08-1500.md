### Problem to Solve

When the CLoD engine hangs before calling `OnBattleStoped()`, `Time.tickCounter()` stops advancing. The `threadLoad_timer` callback detects this as `oneIntAveTick_ms = 100,000,000,000ms` (division by zero `deltaTicks`) and `recentCPUPercent = 0.0%`. Currently nothing acts on this — the timers keep running forever on thread-pool threads while the engine is dead.

**Solution:** Add a consecutive-frozen-tick counter to `Genghis-Class-ThreadLoad.cs`. When N consecutive frozen intervals are detected, call `Environment.Exit(1)` to force-terminate the process.

```csharp
            // Watchdog: detect if the CLoD engine tick counter has frozen
            // (this happens when OnBattleStoped is never called because the engine hung)
            bool isFrozen = (deltaTicks == 0) || (recentCPUPercent == 0.0 && deltaTime.TotalMilliseconds > 5000.0);

            if (isFrozen)
            {
                threadLoadFrozenCount++;
                Console.WriteLine("threadLoad: ENGINE FROZEN tick counter (count: {0} of {1})", threadLoadFrozenCount, threadLoadMaxFrozenConsecutiveTicks);

                if (threadLoadFrozenCount >= threadLoadMaxFrozenConsecutiveTicks)
                {
                    Console.WriteLine("threadLoad: ENGINE FROZEN too many consecutive intervals — forcing process exit via Environment.Exit(1)");
                    Environment.Exit(1);
                }
            }
            else
            {
                threadLoadFrozenCount = 0;
            }
```

- `recentCPUPercent` is a `double` (field on the class). Comparing `== 0.0` is valid C#5.
- `Console.WriteLine` with `{0}` and `{1}` format placeholders is valid C#5.
- `Environment.Exit(1)` is valid C#5.

### How It Works (Runtime Behavior)

| Scenario | Result |
|----------|--------|
| Normal operation (tick counter advancing) | `threadLoadFrozenCount` resets to 0 every interval. No exit. |
| Engine hangs mid-mission (tick counter stops) | `threadLoadFrozenCount` increments each interval. After 3 consecutive frozen intervals (~30 seconds), `Environment.Exit(1)` terminates the process. Console closes immediately. |
| `OnBattleStoped()` called normally | Timers are disposed (previous fix), timer stops, no more callbacks, frozen counter never increments. |
