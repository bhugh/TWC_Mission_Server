## Overview

Currently `Genghis.cs` `DrawFrontLinesPerMapState()` builds a hardcoded `List<List<Point2d>> frontPoints` literal (each inner list = `[RED point, BLUE point]`). We will change it so Genghis reads the points directly from the `.mis` file `Genghis/fronts/genghis-frontlines-FrenchPoint.mis`.

That `.mis` file already contains a `[FrontMarker]` section with lines like:

```
FrontMarker0 10618.90 166919.10 1
FrontMarker1 12535.90 80190.70 2
```

where the last number is the army (`1` = RED, `2` = BLUE, `0` = NEUTRAL). There are no neutral points in this file.

The loader will:
1. Load the `.mis` via `GamePlay.gpLoadSectionFile(...)`.
2. Read the `[FrontMarker]` section.
3. Separate points by army (1 → RED list, 2 → BLUE list).
4. Pair them by encounter order into `List<Point2d>{red, blue}` pairs.
5. Return `List<List<Point2d>>` consumed by `DrawFrontLinesPerMapState()`.

If the file cannot be loaded or yields zero pairs, fall back to the existing hardcoded literal (existing behavior preserved).

### Step 2: Add the loader method

Add a new method to `Genghis.cs` (place it near `DrawFrontLinesPerMapState`, e.g. right before line 4405). Use exactly this C#5 code:

```csharp
public List<List<Point2d>> LoadFrontPointsFromMisFile(string misFilePath)
{
    List<List<Point2d>> result = new List<List<Point2d>>();
    try
    {
        if (string.IsNullOrEmpty(misFilePath)) return result;

        string fullPath = CLOD_PATH + FILE_PATH + misFilePath;
        ISectionFile f = GamePlay.gpLoadSectionFile(fullPath);
        if (f == null) return result;
        if (!f.exist("FrontMarker")) return result;

        int num = f.lines("FrontMarker");
        List<Point2d> redPoints = new List<Point2d>();
        List<Point2d> bluePoints = new List<Point2d>();

        string key = "";
        string value = "";
        for (int i = 0; i < num; i++)
        {
            f.get("FrontMarker", i, out key, out value);
            string[] parts = value.Trim().Split(null);
            if (parts.Length < 3) continue;

            double x = 0;
            double y = 0;
            int army = 0;
            if (!double.TryParse(parts[0], out x)) continue;
            if (!double.TryParse(parts[1], out y)) continue;
            if (!int.TryParse(parts[2], out army)) continue;

            Point2d p = new Point2d(x, y);
            if (army == 1)
            {
                redPoints.Add(p);
            }
            else if (army == 2)
            {
                bluePoints.Add(p);
            }
            // army == 0 (neutral) is skipped intentionally
        }

        // Pair RED[i] with BLUE[i] in encounter order.
        // Index 0 = RED (army 1), index 1 = BLUE (army 2) — matches DrawFrontLinesPerMapState expectation.
        int count = redPoints.Count;
        if (bluePoints.Count < count) count = bluePoints.Count;
        for (int i = 0; i < count; i++)
        {
            List<Point2d> pair = new List<Point2d>();
            pair.Add(redPoints[i]);
            pair.Add(bluePoints[i]);
            result.Add(pair);
        }
    }
    catch (System.Exception ex)
    {
        Console.WriteLine("LoadFrontPointsFromMisFile failed: " + ex.Message);
        return new List<List<Point2d>>();
    }
    return result;
}
```

Notes:
- `Split(null)` splits on whitespace — same pattern already used at Genghis.cs line 9427.
- `out x`, `out y`, `out army` are declared-before-use (C#5 compliant).
- No `$"..."`, no `?.`, no `out var`, no pattern matching.
- Neutral (`army == 0`) points are skipped.
