These .mis files with flak emplacements for various areas are actually not used/disabled in the server right now.  That is because FLAK tends to kill the server - hog 
massive amounts of CPU time, if there is a lot in the server and there is any activity.  Like flak will shoot at any nearby enemy aircraft, even AI.

So with a lot of AI aircraft and a lot of flak in the server, the flak was just killing the CPU.

So now we auto-place flak near objectives, via scripting, only when breather pilots are nearby and headed towards the objective.  

Still these are good flak emplacements for various areas and may be useful for that reason.
